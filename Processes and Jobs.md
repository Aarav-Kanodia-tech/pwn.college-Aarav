# Module 9: Processes and Jobs
## Learnt:
- `ps`, `kill`, `fg`, `bg` commands
- `Ctrl + C` (SIGINT) and `Ctrl + Z` (SIGTSTP) keyboard interrupts
- Standard `ps` argument formats: System V (`-ef`) vs. BSD (`aux`)
- Job management via background execution (`&`) and shell job slots
- Inspecting program exit codes using the special shell variable `$?`
- Managing concurrent tasks, terminating rogue processes, and resuming suspended state
